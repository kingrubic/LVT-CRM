# LVT CRM

Prototype giao diện web CRM nội bộ cho Trường THCS Lê Văn Tám.

## Chạy thử cục bộ

Dự án là một website tĩnh, không cần cài dependency:

```bash
python3 -m http.server 8080
```

Sau đó mở <http://localhost:8080>.

## Cấu trúc

- `index.html`: giao diện và tương tác của prototype.
- `assets/`: tài nguyên hình ảnh công khai.

## Lưu ý bảo mật

Repository này chỉ chứa mã giao diện công khai. Thông tin đăng nhập, khóa phiên, cấu hình máy chủ và dữ liệu thật không được lưu trong Git.
